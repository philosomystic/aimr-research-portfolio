Earlier working framework

Candidate Developmental & Augmentation Variable Architecture (CDAVA)

CDAVA was an earlier working framework. Its useful distinctions have been absorbed into the current HAIDR architecture: configuration variables, participation history and distributions of consequential operations, multilevel outcome vectors, and sustained-capability evaluation.

It is no longer a coequal public framework. Current operational work appears in Study 0 and Developmental Measurement & Inference.
